# Homework_6.1
## Описание:
Домашняя работа по теме "Основы Django".
Приложение написано при помощи фреймворка Django.
Реализован вывод 2 веб-страниц - home и contact - а так же принятие данных, введенных пользователем в форме обратной
связи. Они выводятся в консоль, пользователю же выводится уведомление, что его сообщение успешно отправлено.

## Установка:
1. Клонируйте репозиторий
```
git clone https://github.com/LeslieShmit/homework_6.1.git
```
2. Установите poetry в качестве пакетного менеджера
```
poetry init
```
3. Установите необходимые зависимости
```
poetry install
```
